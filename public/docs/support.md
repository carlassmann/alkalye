# Support

## Get help

Email [assmann@hey.com](mailto:assmann@hey.com) with a short description of the problem.
For MCP connection issues, include the provider, the action attempted, and the approximate time. Never send your Alkalye recovery key or OAuth tokens.

## Disconnect a client

Open Alkalye Settings, disconnect the client under Agents / MCP. This stops future requests from that connection.

## Security reports

Report suspected security or privacy issues to the same address. Do not include sensitive document contents.
