What changed

  • One validated graph on cold open; isolated replica forks and a bounded Effect cache for warm reopening. Live subscriptions still close with their scopes.
  • Compact, validated insertion runs replace repeated per-character snapshot metadata. Older clients receive the legacy format; SQLite heads remain compatible with rollback.
  • Body edits reuse cached normalized text and atom projections. Frontmatter promotion, undo and concurrent edits retain their canonical behavior.
  • Unchanged syntax lines retain their DOM. Link, comment and cursor geometry is measured only where visible, with reads grouped before writes.
  • UI refreshes coalesce per frame. Laser trails retain intermediate points. Multicursor navigation uses indexed offsets and cached grapheme geometry.

Rendering and the remaining gap

120fps means about 8.3ms for the entire frame. This headless browser does not prove that target. At 128 KiB, isolated overlay/projection/link work is about 1.8ms, but native textarea layout and paint still cost more. App typing takes about 50ms at the end, and around 30ms near the top or middle.

Line paint containment reduced an isolated 128 KiB median from 48.8ms to 46.4ms across 15 samples. Overlay and textarea layer promotion made it slower and were discarded. Full-array copies/freezing and cold graph expansion also remain costs. A virtualized editing surface deserves a separate architecture experiment.

Collaboration and sync

24 independently persisted sessions used 12 WebSockets and 12 continuously polling connections. Eight rounds mixed append, top/middle edits and overlapping deletions, with cursor updates every round. Four writers edited offline and reconnected. All replicas converged; readers could not mutate.

Under this same-process load, commit requests measured a 293ms median and 587ms p95. The complete journey processed about 20 edits/second, including client SQLite/CRDT work, two sync barriers and presence assertions. This is a correctness stress test, not isolated server capacity. Sustained 24-browser performance remains unmeasured.

Verification and reproducibility

bun run check passes: 439 tests, 8,723 assertions, types, formatting and fast browser journeys. Separate browser module/editor tests cover 200,000-character checkpoints, 128 KiB files, offline recovery, revoked access, IME, Unicode and 512 cursors. Opus reviewed the changes and found frontmatter/Unicode edge cases that were fixed.

The probe starts at trusted input and ends after the required source/DOM state at an animation-frame paint opportunity. It excludes command overhead. RAF callback timings cover only those JavaScript callbacks, excluding input handlers, layout, rasterization and compositing. Production bundles and service-worker versions were checked before measuring; compact local caches were populated first.

Plain prose, fenced-code and long-line fixtures are available in the runner; this app comparison used the rich fixture. Mobile, throttled hardware and sustained 24-browser rendering are not covered by these numbers.
