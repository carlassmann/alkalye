Interaction follow-up

7 October 2026. These narrow experiments follow the comparison with main. They compare rewrite revisions or implementation paths; main was not rerun here.

Body edits remain incremental after metadata changes

Merged frontmatter can leave raw and canonical atom arrays with different lengths. The old cache rejected those arrays, rebuilding the whole source after each keystroke. The fix maps body splices between the arrays and verifies their anchors. Header-boundary mismatches still use the full projection.

Existing history, body middle 102.0ms 2.8ms

Five trusted keystrokes per position and scenario, forty samples total. Before: 71b8f41; after: 3185162. This is a history-heavy disposable profile, not a fresh document. Every edit passed exact-source and durable-save checks. Service-worker and browser caches were removed before boot; loaded entry script sizes and hashes were checked. Earlier samples with uncertain cached assets were discarded.

The interval runs from native beforeinput to the observer after the app's input handler. The largest after interval was 7.9ms. Animation-frame opportunities took longer. A headless browser near 60Hz cannot establish 120Hz pixel presentation.

The public Replica probe also checks prepare, apply and source projection after retitling, concurrent metadata, peer edits and undo. Correctness checks cover replay, checkpoints, whole-body deletion, empty EOF headers and insertion anchors.

Native search highlights reduce manual geometry work

Inactive matches use the browser's CSS Custom Highlight API. The active match keeps its navigation overlay; unsupported browsers keep the rectangle-based fallback. Five alternating trials per mode used the same 35,018-character source with 12,002 matches.

Distant search selection stays within the viewport

The next fix establishes the target viewport and selection together. Previously, selecting a distant match painted against the old viewport first, expanding the whole document. A pre-reveal experiment failed and was discarded. The accepted change also removes a duplicate reveal and retains full native rendering for long selections.

Changes kept and rejected

Library synchronization now skips a second save after a successful, clean synchronization. Real IndexedDB and authenticated HTTP tests cover offline reloads, revoked access, retries, and interruption during concurrent edits. One redundant summary projection attempt disappears; actual changed writes and network pulls remain the same.

Accepted-cache replicas remain isolated between overlapping sessions. Direct reuse failed the public integration checks. An Effect HashMap prototype made copies cheaper but lookups and scans much slower than native Map in Bun. Neither unsafe cache reuse nor that map replacement entered production.
