# Alkalye themes

Each `.theme.md` file is a complete theme. Import it through **Settings → Themes → Upload theme**, or paste the entire Markdown into a theme workbench. CSS, HTML, fonts, images, and licenses travel together.

[Syntwin](syntwin.theme.md) provides subtle branding for documents, PDFs, and slides, including light and dark styles. No ZIP, build script, or separate assets are required.

[Bundeswehr](bundeswehr.theme.md) adapts the current Bundeswehr identity with Bebas Neue / PT Sans, original light/dark logos, and a narrow polygon border. It supports document, slideshow, and white-paper PDF rendering. Fonts, artwork, and source references are embedded.

[Letter](letter.theme.md) is a monospaced letter and invoice layout in the spirit of iA Writer's PDF export, set in Geist Mono. It prints the sender block as a right-hand letterhead column, totals as separate table row groups, and company details as small print.

Optional examples: Syntwin [document](examples/syntwin-document.md) and [talk](examples/syntwin-talk.md), and a [letter](examples/letter.md).

For your own theme, use **New from default** in Alkalye and follow the [theme authoring guide](../public/docs/theming-guide.md).
