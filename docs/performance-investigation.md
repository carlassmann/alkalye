# Next performance work

The [fresh comparison](../public/docs/performance-interaction.html) measures main `a749728` against rewrite `275be37`. This investigation follows that run; it does not replace its timings.

## Change verified

`BackgroundWork` now checks Effect's `Latch.isOpen()` before allocating a timeout race. Closed-latch waits retain their deadlines, interruption and scope cleanup. For 2,000 open-latch waits, an old/new/new/old module experiment reduced scheduler dispatch requests from six to two. Warm elapsed time fell from 2.28 ms to 0.36 ms. This does not establish a browser task or garbage-collection improvement.
